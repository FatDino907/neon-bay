# NEON BAY: Street Legend

An original top-down open-world browser game starring **Shane**, set in the fictional neon city of Neon Bay.
Pure HTML5 canvas + JavaScript (no frameworks). Plays best on a phone (portrait or landscape); keyboard and game controllers work too.

**Play:** https://fatdino907.github.io/neon-bay/

- Touch: drag the left side to move/steer, ZAP / PUNCH / CAR / RUN buttons on the right, tap the minimap for the full map.
- Keyboard: WASD/arrows, E car, Space zap, Q punch, Shift run/drift, M map, R radio, P pause.
- Controller: left stick, X/RT zap, A punch, Y car, B/LT run/drift, Start pause.

Progress saves in the browser (localStorage). Add `?reset=1` to the URL to start completely fresh.
All characters, places, vehicles, music and art are original.
